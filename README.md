# TPSai Analysis

Analysis code and reports for the development and validation of the Trust in Psychological Support from AI (TPSai) scale.

## Reports

| Report | Survey | Description |
|-----------------|--------------|--------------------------------|
| [Expert Evaluation](1_expert-evaluation.html) | [Experts](surveys/expert-evaluation_qs.csv) | Expert evaluation of item pool via inter-rater agreement |
| [Item Reduction](2_item-reduction.html) | [Pilot](surveys/pilot-test_qs.csv) | Identifying items to drop or merge through quantitative pilot |
| [EFA](3_EFA.html) | [EFA](surveys/efa_qs.csv) | Exploratory factor analysis |
| [CFA](4_CFA.html) | [CFA](surveys/cfa_qs.csv) | Confirmatory factor analysis |
| [Study 2 and 3](5_study_2-3.html) | [CFA](surveys/cfa_qs.csv) | Scale comparisons with single-item trust/distrust, PTT-A, ETMCQ, Generative AI Dependency (Study 2) and exploratory analysis of frequency of use, platform of choice, age, and psycotherapy exposure (Study 3) |

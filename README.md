# TPSai Analysis

Analysis code and reports for the development and validation of the Trust in Psychological Support from AI (TPSai) scale.

## Reports

| Report | Survey | Description |
|--------------------|--------------------|--------------------------------|
| [Expert Evaluation](https://ricvolpe.github.io/tpsai-analysis/1_expert-evaluation.html) | [Experts](surveys/expert-evaluation_qs.csv) | Expert evaluation of item pool via inter-rater agreement |
| [Item Reduction](https://ricvolpe.github.io/tpsai-analysis/2_item-reduction.html) | [Pilot](surveys/pilot-test_qs.csv) | Identifying items to drop or merge through quantitative pilot |
| [EFA](https://ricvolpe.github.io/tpsai-analysis/3_EFA.html) | [EFA](surveys/efa_qs.csv) | Exploratory factor analysis |
| [CFA](https://ricvolpe.github.io/tpsai-analysis/4_CFA.html) | [CFA](surveys/cfa_qs.csv) | Confirmatory factor analysis |
| [Scale Evalution](https://ricvolpe.github.io/tpsai-analysis/5_evaluation.html) | [CFA](surveys/cfa_qs.csv) | Item and factor scores, concurrent and construct validity, test-rest reliability, and exploratory analysis |
